# 🩺 MamaMaria - Hasta Takip Uygulaması

MamaMaria, ALS gibi kronik hastalıklara sahip bireylerin günlük sağlık durumlarının kolayca takip edilmesini sağlayan kullanıcı dostu bir uygulamadır. Hem hasta yakınları hem de sağlık personelleri için tasarlanmıştır.

---

## 🚀 Özellikler

- 👤 Kullanıcı girişi ve oturum yönetimi (Firebase Auth ile)
- 🏥 Hasta ekleme, düzenleme, silme
- 📊 Vital değer takibi (nabız, tansiyon, ateş vb.)
- 💊 İlaç planlama, saatlik doz takibi
- 📄 PDF formatında veri çıktısı alma
- 🔗 Hasta verilerini farklı kullanıcılarla paylaşma (devam eden geliştirme)
- 🌐 Responsive tasarım, mobil uyumlu yapı

---

## 🧰 Kullanılan Teknolojiler

- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Backend:** Firebase (Auth, Firestore, Storage)
- **Araçlar:** VS Code, Git, GitHub
- **Planlanan:** React Native ile mobil uygulama
